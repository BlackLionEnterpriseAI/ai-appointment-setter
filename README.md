# Black Lion Automation – AI Appointment Setter Agent

## 🚀 Overview  
This repository contains the **AI Appointment Setter Agent** designed and built by **Black Lion Automation**.  
This agent books appointments, qualifies leads, handles objections, and integrates with CRM + calendar systems automatically.

### Capabilities
- 24/7 appointment scheduling  
- Lead qualification using dynamic questions  
- Objection handling  
- Instant responses across platforms  
- CRM syncing  
- Pipeline automation  
- Follow-up sequences  

---

## 🧩 Folder Structure
scripts/                → Conversation scripts
prompts/                → AI system & behavior prompts
workflows/              → Pre-built automations for Zapier, Make, GHL, ManyChat
integrations/           → Setup guides for calendars & CRMs
documentation/          → Technical docs & user guides
demo/                   → Sample conversations & demo scripts
assets/                 → Images, branding, or videos

---

## 📦 Deployment Steps  
1. Import the workflow file (Zapier/Make/GHL/ManyChat).  
2. Copy prompts into the automation.  
3. Connect calendar + CRM.  
4. Customize business details.  
5. Test conversation.  
6. Deploy live.
